## [17.0.1.0.2] - 2024-03-10

### Added
- Complete rewrite for Odoo 17 compatibility
- OWL 2 JavaScript architecture with ES6+ modules
- Time-based message editing and deletion
- Admin can delete any message within 48 hours
- Full integration with Odoo 17 message actions registry
