# Contributing to Chat Edit & Delete

Thank you for your interest in contributing to Chat Edit & Delete for Odoo!

## How to Contribute

### Reporting Bugs
- Use the issue tracker on GitHub
- Include Odoo version, browser, and steps to reproduce
- Provide screenshots if applicable

### Suggesting Features
- Open an issue with the "enhancement" label
- Describe the use case and expected behavior
- Consider if it benefits the broader community

### Pull Requests
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Test thoroughly on Odoo 17
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Development Guidelines

### Code Style
- Follow PEP 8 for Python
- Use ES6+ for JavaScript
- Write meaningful commit messages
- Add tests for new features

### Testing
- Test on different Odoo versions if applicable
- Verify UI compatibility
- Check for security implications

### Documentation
- Update README.md for user-facing changes
- Update CHANGES.md for version history
- Add inline comments for complex logic
